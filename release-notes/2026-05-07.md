# OpenClaw v2026.5.7 版本發佈說明

[GitHub Release](https://github.com/openclaw/openclaw/releases/tag/v2026.5.7)

## ⚠️ 升級前必讀

### Breaking Changes 摘要

| 項目 | 影響 | 行動 |
|------|------|------|
| Channels CLI 重構 | `openclaw channels list` 預設僅顯示 channel，模型認證資訊移至 `openclaw models auth list` | 查詢模型認證改用 `models auth list` 或 `openclaw status` ([#78456](https://github.com/openclaw/openclaw/pull/78456)) |
| Cron JSON 輸出變更 | `cron list --json` 與 `cron show --json` 新增 `status` 欄位 | 外部工具可直接讀取狀態，無需自行推導 ([#78701](https://github.com/openclaw/openclaw/pull/78701)) |

### 新功能亮點

- **OpenAI `chat-latest` 支援**：可直接使用 ChatGPT Instant API 別名，無需變更預設模型
- **Channels CLI 重構**：`channels list` 更簡潔，`--all` 顯示完整資訊，模型認證移至獨立指令
- **Cron 狀態 JSON 輸出**：外部工具可直接讀取 disabled/running/ok/error/skipped/idle 狀態
- **Discord 語音優化**：延長靜音寬限期至 2.5 秒，減少卡頓，新增 `voice.captureSilenceGraceMs` 設定
- **Plugin 發佈強化**：重試暫時性 ClawHub CLI 依賴安裝失敗，驗證每個預期套件版本

## 概覽

### 功能更新 (Features)

- ⭐⭐⭐ Plugin 發佈強化：重試暫時性 ClawHub CLI 依賴安裝失敗、保留通過預覽的 plugin 可發佈性、驗證每個預期 ClawHub 套件版本
- ⭐⭐⭐ Channels CLI 重構：`channels list` 預設僅顯示 channel，`--all` 顯示 bundled 與 catalog channel，渲染 installed/configured/enabled 狀態，模型認證與使用詳情移至 `models auth list`、`status`、`models list` ([#78456](https://github.com/openclaw/openclaw/pull/78456)) 感謝 @sliverp
- ⭐⭐ Cron JSON 狀態輸出：`cron list --json` 與 `cron show --json` 包含計算的 `status`，外部工具可直接讀取 disabled/running/ok/error/skipped/idle 狀態 ([#78701](https://github.com/openclaw/openclaw/pull/78701)) 感謝 @aweiker
- ⭐⭐ OpenAI `chat-latest`：支援 `openai/chat-latest` 作為明確的直接 API key 模型覆寫，可嘗試移動的 ChatGPT Instant API 別名而不變更穩定預設模型
- ⭐⭐ Discord 語音優化：延長預設 post-speech 靜音寬限期至 2.5 秒，新增 `voice.captureSilenceGraceMs` 設定，收緊 spoken-output prompt 以處理 live STT 片段。感謝 @vincentkoc
- ⭐⭐ Discord 語音權限稽核：`channels capabilities` 與 `channels status --probe` 檢查語音頻道權限（Connect/Speak/Read Message History），在 `/vc join` 前顯示缺失權限
- ⭐ Codex 審批模式改進：停止預設安裝 pre-guardian native `PermissionRequest` hook，讓 Codex reviewer 先批准安全指令；在活動 session 視窗內記住 `allow-always` 決定；plugin 審批請求驗證/渲染實際允許的決定。感謝 @shakkernerd
- ⭐ WhatsApp 主動傳送優化：透過 Baileys LID forward mappings 路由主動電話號碼傳送，LID 位址聯絡人可收到 agent 訊息而非建立僅有傳送者的幽靈聊天 ([#74925](https://github.com/openclaw/openclaw/pull/74925)) 感謝 @edenfunf
- ⭐ WhatsApp 媒體回覆修復：captioned `MEDIA:` 指令自動回覆僅傳送一次，不再先發出空媒體訊息 ([#78770](https://github.com/openclaw/openclaw/pull/78770)) 感謝 @ai-hpc
- ⭐ Telegram 模型選擇器：解析包含點的 provider id（如 `hf.co`），使其在 `/models` 回呼按鈕中渲染為 inline keyboard 按鈕 ([#38745](https://github.com/openclaw/openclaw/pull/38745))
- ⭐ Telegram 輪詢看門狗：將輪詢看門狗綁定至 `getUpdates` 存活度，無關的出站 Bot API 呼叫無法掩蓋卡住的入站輪詢器 ([#78422](https://github.com/openclaw/openclaw/pull/78422)) 感謝 @ai-hpc
- ⭐ 模型供應商改進：正規化 APNG 嗅探的 PNG 上傳、保留 Gemini 3 tool-call thought-signature 重播（含後備簽名）、接受舊版 `__env__:VAR` 自訂 provider 金鑰、修復 snake_case tool-call 轉錄清理 ([#51881](https://github.com/openclaw/openclaw/issues/51881), [#48915](https://github.com/openclaw/openclaw/issues/48915), [#77566](https://github.com/openclaw/openclaw/issues/77566), [#42858](https://github.com/openclaw/openclaw/issues/42858))
- ⭐ Subagent 存檔 TTL：完成的 session-mode subagent 登錄列遵循 `agents.defaults.subagents.archiveAfterMinutes` 而非硬編碼 5 分鐘 TTL ([#78263](https://github.com/openclaw/openclaw/pull/78263)) 感謝 @arniesaha
- ⭐ Plugin channel 設定轉發：從非 bundled 外部 plugin 設定條目轉發 `setChannelRuntime`，延遲的外部 channel runtime 初始化器在啟動輪詢前安裝 ([#77799](https://github.com/openclaw/openclaw/pull/77799)) 感謝 @openperf
- ⭐ Gateway 任務清理：調和已消失的 CLI run-context 任務與綁定的 channel hot-reload 延遲，避免陳舊任務記錄永久阻塞 Discord/Slack/Telegram 重載
