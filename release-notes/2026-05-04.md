# OpenClaw v2026.5.4 版本發佈說明

[GitHub Release](https://github.com/openclaw/openclaw/releases/tag/v2026.5.4)

> 包含 v2026.5.3-1 hotfix 修復。

## ⚠️ 升級前必讀

### Breaking Changes 摘要

| 項目 | 影響 | 行動 |
|------|------|------|
| WebSocket auth scope 收緊 | 未綁定的 WebSocket 認證範圍將被箝制 | 確認自訂 WebSocket 客戶端傳遞正確的 scope 參數 |
| 設備配對需 pairing scope | 配對端點新增 scope 驗證 | 確認配對流程使用正確的 `pairing` scope |
| QQBot 私人命令不暴露至框架層 | 私人命令不再顯示在公開頻道介面 | 確認依賴公開介面顯示私人命令的流程已更新 |
| Windows SystemRoot/WINDIR 驗證 | Windows 環境變數需通過安全性驗證 | 確認自訂 Windows 部署的環境變數設定正確 |

### 新功能亮點

- **Google Meet/Voice Call：Twilio 撥入 + Gemini 即時語音橋接** — 透過 Twilio 電話撥入，經 Gemini 即時語音模型進行對話
- **WhatsApp Channel/Newsletter 支援** — 新增 WhatsApp 頻道與電子報發佈能力
- **Exec Approvals Tree-sitter Shell 解釋器** — 使用 tree-sitter 解析 shell 命令，提供更友善的審批提示
- **Sandbox 容器分片** — 支援多容器分片部署，提升沙箱隔離與資源利用率
- **Control UI 全面改進** — Agent 名稱麵包屑導航、可摺疊 Cron 側邊欄、響應式聊天設計

## 安全性提升 (Security) - by Star Rating

### ⭐⭐⭐ WebSocket auth scope 箝制 ([#77413](https://github.com/openclaw/openclaw/pull/77413))

- **用途**: 箝制未綁定的 WebSocket 認證範圍，防止過度授權
- **解決問題**: WebSocket 認證可獲得超出需要的 scope，違反最小權限原則
- **影響**: WebSocket 連線僅持有必要的最小 scope

```text
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  WebSocket   │────►│   Auth       │────►│  Scope       │
│  Connect     │     │   Token      │     │  Validation  │
└──────────────┘     └──────────────┘     └──────────────┘
                                                  │
                                          ┌───────┴───────┐
                                          ▼               ▼
                                   ┌────────────┐  ┌────────────┐
                                   │  Unbound   │  │  Clamped   │
                                   │  (before)  │  │  (after)   │
                                   │  All scopes│  │  Min scope │
                                   └────────────┘  └────────────┘
```

### ⭐⭐⭐ 設備配對需 pairing scope ([#76377](https://github.com/openclaw/openclaw/pull/76377))

- **用途**: 設備配對端點新增 `pairing` scope 驗證
- **解決問題**: 配對端點缺乏 scope 檢查，可能被未授權的 token 濫用
- **影響**: 配對操作需要明確的 `pairing` scope 授權

```text
                                                  │
                                          ┌───────┴───────┐

                                   ┌────────────┐  ┌────────────┐
                                   │ Has pairing│  │ Missing    │
                                   │ scope: OK  │  │ scope: 403 │
```

### ⭐⭐⭐ Windows SystemRoot/WINDIR 安全性驗證 ([#74458](https://github.com/openclaw/openclaw/pull/74458), [#74454](https://github.com/openclaw/openclaw/pull/74454), [#77470](https://github.com/openclaw/openclaw/pull/77470), [#77472](https://github.com/openclaw/openclaw/pull/77472))

- **用途**: 驗證 Windows 環境的 `SystemRoot` 和 `WINDIR` 環境變數，防止路徑注入
- **解決問題**: 惡意的環境變數可劫持系統路徑，導致提權或程式碼注入
- **影響**: Windows 部署不受路徑注入攻擊影響

```text
                                                  │
                                          ┌───────┴───────┐
                                          ▼               ▼
                                   ┌────────────┐  ┌────────────┐
                                   │  Valid:    │  │  Invalid:  │
                                   │  Proceed   │  │  Reject    │
                                   └────────────┘  └────────────┘
```

### ⭐⭐⭐ Browser SSRF：嚴格 current-URL 檢查與導航策略 ([#75731](https://github.com/openclaw/openclaw/pull/75731))

- **解決問題**: 瀏覽器 tab 可透過導航繞過 SSRF 防護，存取內部網路

```text
                                          ▼               ▼
                                   ┌────────────┐  ┌────────────┐
```
