## 錯誤修復 (Bug Fixes) - by Star Rating

### ⭐⭐ Doctor/Codex：還原 2026.5.5 doctor 修復（修復 OAuth 路由） ([#78407](https://github.com/openclaw/openclaw/pull/78407))

- **用途**: 還原 v2026.5.5 中 doctor 對 openai-codex 路由的修復，該修復意外破壞了 OAuth 路由
- **解決問題**: v2026.5.5 的 doctor 修復導致 OAuth 路由解析失敗，使用者無法透過 OAuth 認證使用 Codex 模型
- **影響**: OAuth 路由恢復正常，Codex 模型可透過 OAuth 正確存取

### ⭐ Plugins/runtime fetch：移除 symbol metadata ([#77846](https://github.com/openclaw/openclaw/pull/77846))

- **用途**: 插件執行時期 fetch 時移除 symbol 類型的 metadata
- **解決問題**: symbol metadata 在序列化時導致錯誤
- **影響**: 插件 fetch 不再因 symbol 序列化而失敗

### ⭐ Debug proxy：正規化 header 字典

- **用途**: Debug proxy 正規化 HTTP header 字典格式
- **解決問題**: 非正規化的 header 字典在代理轉發時可能導致 header 重複或遺失
- **影響**: Debug proxy header 處理更可靠

### ⭐ Web fetch：timeout 後的清理邊界 ([#78439](https://github.com/openclaw/openclaw/pull/78439))

- **用途**: Web fetch 在 timeout 後正確清理資源
- **解決問題**: timeout 後未清理的連線和緩衝區導致資源洩漏
- **影響**: Web fetch timeout 不再造成資源洩漏
