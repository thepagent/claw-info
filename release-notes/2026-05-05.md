## 功能更新 (Features) - by Star Rating

### ⭐⭐ Exec Approvals：Windows rename-overwrite 回退 ([#77785](https://github.com/openclaw/openclaw/pull/77785), [#77907](https://github.com/openclaw/openclaw/pull/77907))

- **用途**: 在 Windows 上當 rename-overwrite 失敗時，使用回退策略完成檔案替換
- **解決問題**: Windows 上跨磁碟 rename 不支持原子替換，導致審批流程失敗
- **影響**: Windows 審批流程穩定完成

### ⭐⭐ iOS 配對：私有 LAN ws:// 支援 ([#47887](https://github.com/openclaw/openclaw/pull/47887))

- **用途**: iOS 設備配對支援透過私有區域網路 `ws://` 連線
- **解決問題**: iOS 設備在沒有 HTTPS 的區域網路中無法完成配對
- **影響**: 區域網路環境下的 iOS 配對體驗改善

### ⭐⭐ Control UI 改進

- **用途**: 新增 compaction 顯示狀態、session runtime 篩選器、聊天效能優化
- **解決問題**: Control UI 缺乏 compaction 狀態顯示，session 篩選不便，聊天載入慢
- **影響**: 管理介面資訊更完整、操作更流暢

### ⭐⭐ 影片生成：aspect-ratio/resolution 提示

- **用途**: 影片生成工具新增長寬比和解析度提示參數
- **解決問題**: 影片生成缺乏控制輸出尺寸的能力
- **影響**: 使用者可指定影片的長寬比和解析度

### ⭐ Plugins/diagnostics：可操作的 source-only 警告 ([#77835](https://github.com/openclaw/openclaw/pull/77835))

- **用途**: 插件診斷訊息新增可操作的 source-only 警告，指引使用者解決問題
- **解決問題**: 診斷訊息僅列出問題，不提供解決方向
- **影響**: 使用者可根據警告快速定位和解決插件問題

### ⭐ TUI：跳過 respawn wrapper、過期 session 修復

- **用途**: TUI 跳過不必要的 respawn wrapper，修復過期 session 顯示問題
- **解決問題**: respawn wrapper 導致不必要的行程重啟；過期 session 顯示異常
- **影響**: TUI 啟動更快速，session 列表顯示正確

### ⭐ Gateway：shutdown 清理、status 改進

- **用途**: Gateway shutdown 時正確清理資源，status 命令顯示更完整的資訊
- **解決問題**: shutdown 時資源未完全釋放；status 資訊不夠詳細
- **影響**: Gateway 關機更乾淨，診斷更方便

### ⭐ Plugins/update：保持官方插件同步

- **用途**: 插件更新時自動保持官方插件版本同步
- **解決問題**: 官方插件更新可能被跳過，導致版本不一致
- **影響**: 官方插件始終保持最新版本

## 安全性提升 (Security) - by Star Rating

### ⭐⭐⭐ LINE：reject dmPolicy "open" without wildcard allowFrom ([#78316](https://github.com/openclaw/openclaw/pull/78316))

- **用途**: 當 LINE 頻道設定 `dmPolicy="open"` 時，要求必須包含萬用字元 `allowFrom`
- **解決問題**: `dmPolicy="open"` 在沒有 `allowFrom` 萬用字元的情況下等同於公開存取，存在安全風險
- **影響**: LINE 開放 DM 必須明確設定 `allowFrom` 萬用字元

```text
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  LINE DM     │────►│  dmPolicy    │────►│  allowFrom   │
│  Request     │     │  = "open"    │     │  Check       │
└──────────────┘     └──────────────┘     └──────────────┘
                                                  │
                                          ┌───────┴───────┐
                                          ▼               ▼
                                   ┌────────────┐  ┌────────────┐
                                   │  Has       │  │  Missing   │
                                   │  wildcard: │  │  wildcard: │
                                   │  Allow     │  │  Reject    │
                                   └────────────┘  └────────────┘
```

### ⭐⭐ Docker：強化容器（drop NET_RAW/NET_ADMIN）

- **用途**: Docker 容器丟棄 `NET_RAW` 和 `NET_ADMIN` 網路能力
- **解決問題**: 預設容器能力過多，包含不需要的網路管理能力
- **影響**: 容器無法進行網路嗅探或修改網路配置，降低攻擊面

## 錯誤修復 (Bug Fixes) - by Star Rating

### ⭐⭐⭐ Feishu：補全遺失的原生主題起始 thread ID ([#78262](https://github.com/openclaw/openclaw/pull/78262))

- **用途**: 補全飛書對話中遺失的原生主題起始 thread ID
- **解決問題**: 飛書話題討論串缺少起始 thread ID，導致回覆無法正確串接
- **影響**: 飛書話題討論串回覆正確歸屬到對應話題

```text
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  Feishu      │────►│  Topic       │────►│  Hydrate     │
│  Message     │     │  Thread      │     │  Missing     │
└──────────────┘     └──────────────┘     │  Thread IDs  │
                                          └──────────────┘
                                                  │
                                                  ▼
                                         ┌──────────────┐
                                         │  Replies     │
                                         │  Correctly   │
                                         │  Threaded    │
                                         └──────────────┘
```

### ⭐⭐ Telegram/Codex：保持進度草稿可見 ([#75641](https://github.com/openclaw/openclaw/pull/75641), [#77949](https://github.com/openclaw/openclaw/pull/77949))

- **用途**: 確保 Telegram 和 Codex 串流中的進度草稿訊息保持可見
- **解決問題**: 進度草稿訊息在更新過程中被刪除或覆蓋，使用者看不到即時進度
- **影響**: 使用者可在 Telegram 和 Codex 中持續看到執行進度

### ⭐⭐ xAI：停止向 Grok 發送 OpenAI-style reasoning effort

- **用途**: 停止向 xAI/Grok 模型發送 OpenAI 風格的 `reasoning_effort` 參數
- **解決問題**: Grok 模型不支援 `reasoning_effort`，發送該參數導致請求失敗
- **影響**: xAI/Grok 模型請求不再因不支援的參數而失敗

### ⭐⭐ Matrix/approvals：重試投遞 ([#78179](https://github.com/openclaw/openclaw/pull/78179))

- **用途**: Matrix 審批訊息投遞失敗時自動重試
- **解決問題**: Matrix 審批訊息因網路問題投遞失敗後不重試
- **影響**: Matrix 審批訊息投遞更可靠

### ⭐⭐ Discord/gateway：heartbeat ACK 時序修復 ([#77668](https://github.com/openclaw/openclaw/pull/77668), [#78087](https://github.com/openclaw/openclaw/pull/78087))

- **用途**: 修復 Discord Gateway heartbeat ACK 時序計算
- **解決問題**: heartbeat ACK 時序計算不準確，導致非必要的重連
- **影響**: Discord 連線更穩定，減少非必要的重連

### ⭐⭐ Discord/guilds：路由純文字控制命令 ([#78080](https://github.com/openclaw/openclaw/pull/78080))

- **用途**: Discord guilds 正確路由純文字格式的控制命令
- **解決問題**: 純文字控制命令在 Discord guilds 中無法正確路由到處理器
- **影響**: Discord guilds 中純文字控制命令正常運作

### ⭐ Doctor/Codex：修復 legacy openai-codex 路由

- **用途**: 修復 Doctor 和 Codex 中舊版 `openai-codex` 路由配置
- **解決問題**: 舊版 `openai-codex` 路由在新版本中無法正確解析
- **影響**: 舊版 openai-codex 路由配置可正確升級
